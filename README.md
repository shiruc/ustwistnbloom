# StudioDrive

Static single-page AI studio dashboard inspired by modern AI workspaces.

## Usage

1. Copy `index.html`, `style.css`, and `script.js` into your GitHub repository.
2. Enable GitHub Pages for the repository (Settings → Pages → Deploy from branch).
3. Visit the GitHub Pages URL to view the site.

## Customize

- Update the text in `index.html` for your branding.
- Tweak colors in `style.css` under `:root` and `body.dark`.
- Adjust interactivity in `script.js`.
